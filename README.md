# RedFlag Lens

An evidence-cited early-warning tool that reads Indian annual reports and flags risk sentences (going-concern doubts, defaults, penalties, litigation, auditor qualifications) for **credit analysts at banks and NBFCs**. NLP course project, Industry Track.

## Status (M1 + M2)
- 26 annual reports (10 distressed, 16 healthy), 8,303 pages → **96,792 clean sentences** with section and page.
- Company-wise train / val / test split, plus a held-out backtest company (Gensol).
- Annotation guide v1.1, 300-sentence pilot labelled, blind sheet ready for the human agreement check.
- Data card, exploratory and statistical analysis: `reports/figures/`, `reports/eda_stats.json`.

## Setup
```bash
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python pymupdf pysbd pandas scikit-learn scipy matplotlib rapidfuzz openpyxl
src/prep/00_download.sh           # fetch the 26 PDFs from the BSE archive
./run_prep.sh                     # rebuild everything (about 4 min)
```

## Layout
```
data/raw/            PDFs (git-ignored) + manifest.csv + candidates.csv (download list)
data/interim/        blocks.jsonl (text + section + page), sentences.jsonl, section_coverage.csv
data/splits/         company lists per split + split_summary.csv
data/annotations/    guide.md, pilot_300_labelled.*, pilot_100_blind_for_humans.xlsx
data/DATA_CARD.md
src/prep/            01_ingest → 02_extract → 03_sentences → 04_split_sample → 05_eda → 06_agreement
reports/             figures + statistics
docs/                research brief, product spec, milestone plan, dataset plan
```

## Agreement check (team to do)
1. Fill in `data/annotations/pilot_100_blind_for_humans.xlsx` using `guide.md`. Don't look at the pilot labels.
2. Save it as `pilot_100_human_<name>.xlsx`.
3. Run `.venv/bin/python src/prep/06_agreement.py data/annotations/pilot_100_human_<name>.xlsx` to get Cohen's kappa and the list of disagreements.

## Data files in this repo
- `data/raw/manifest.csv`: every PDF with its source URL, page count and SHA-256. The PDFs themselves are not committed; fetch them with `src/prep/00_download.sh`.
- `data/interim/sentences.jsonl.gz`: the 96,792 cleaned sentences (gunzip to use). `blocks.jsonl` is regenerated by `run_prep.sh`.
