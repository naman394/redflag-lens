This is the product. The analyst opens the dashboard and uploads a PDF. Before anything, it checks the file: is it a real PDF, is it password-locked, is it a scanned image with no text. Then the model reads every sentence; on a laptop with FinBERT this takes about two and a half minutes, on a GPU server with DeBERTa about five seconds. At the top you see five numbers, with severe warning signs first, and a short summary. Below is the table of findings, each with its risk type, score and page number, so you can open the PDF and check. You can filter to severe only, or open the review tier to see lower-confidence flags. The analyst can give thumbs up or down, and that feedback becomes new training data. It is built with Streamlit for the screen, FastAPI for the backend, and a Docker file so it can be deployed. Let me show it live now.
