M2 · Privacy and ethics

Public filings, company-level analysis, careful wording

Data source

Statutory public disclosures only. Raw PDFs are not redistributed; a manifest records each source URL and checksum.

Personal data

Director and auditor names appear in the text. We profile companies, not people: no person index, no person-level scores (DPDP Act 2023).

No fraud verdicts

Outputs say “review recommended” with evidence. The analyst decides; RBI requires a borrower hearing before any fraud tag.

Deployment

Classifiers run on the bank’s own CPU servers; the LLM step is optional or a local model, so borrower documents need not leave the bank.

17 · Known biases: large-cap healthy group, 10 distressed reports, English only, text-layer PDFs only

Privacy is light because the data is public, but we still handle it deliberately. Names of directors appear in the text; we keep them only as entities inside evidence sentences. The bigger ethical risk is wrongly labelling a company as fraudulent, so the product never gives verdicts, only evidence for a human to review.
