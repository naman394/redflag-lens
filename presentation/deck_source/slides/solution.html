M1 · Proposed solution

From PDF to an evidence-cited red-flag report

1 · Extract

PDF text, ₹ repair, report sections

2 · Detect

Is this sentence a risk?

3 · Classify

5 categories; specific red flag vs boilerplate

4 · Extract facts

Entities, ₹ lakh/crore, dates, events

5 · Link

Related statements; year-over-year changes

6 · Report

Agents write a summary; a verifier drops unsupported claims

Output for the analyst

A dashboard of red flags by category. Each one shows the sentence, page, amount, counterparty and related statements, plus a ~20-item checklist (going concern, defaults, unpaid dues, auditor qualifications, penalties…).

NLP techniques covered

TF-IDF + logistic regression baseline, fine-tuned transformer (FinBERT), NER with Indian money rules, sentence embeddings, and an LLM agent layer grounded in the evidence.

4

The product in one pipeline. Steps 1 to 4 are classical and transformer NLP; step 5 uses embeddings; step 6 is the agentic layer. The important design choice: the LLM never reads the whole report. It only sees evidence the earlier models found, and a verifier removes any claim the evidence doesn’t support. That keeps every finding traceable.
